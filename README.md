# U.S. Insurance Agency website

Static one-page website for U.S. Insurance Agency, 25 Jericho Turnpike, Jericho, NY 11753.
Plain HTML, CSS and JavaScript. No build step.

## Files

- `index.html` : the page
- `css/style.css` : styles (light and dark theme aware)
- `js/main.js` : coverage tabs and hero animation
- `.nojekyll` : tells GitHub Pages to serve the files as they are

## Publish with GitHub Pages

1. Create a new repository on GitHub.
2. Upload all of these files, keeping the `css` and `js` folders.
3. Go to Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
5. Your site goes live at `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` in a minute or two.

## Before going live

- The coverage details in the Sample coverage summary are generic examples. Replace them in `js/main.js` with your real information.
- Confirm office hours, then update the hours text in `index.html`.
- Add your logo, office photos and licensing details if you want them shown.
